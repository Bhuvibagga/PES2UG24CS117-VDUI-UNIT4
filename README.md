## Case-Based Activity: Auditing ChatViz at RideNow

### Overview
This activity focuses on auditing ChatViz, a conversational visualization assistant used by RideNow, a ride-hailing company. The objective is to understand how natural-language queries are interpreted, converted into chart specifications, modified through conversations, and validated to ensure accurate visualizations.

### Objectives
- Understand Natural Language to Visualization (NL2Vis).
- Identify abstract tasks from natural-language queries.
- Handle spelling errors and ambiguous requests.
- Understand conversational context and dialogue state management.
- Generate and validate chart specifications.
- Apply chart edits using natural-language instructions.
- Identify visualization failure modes and propose mitigation strategies.

### Cases Covered

| Case | Topic |
|---|---|
| Case 1 | Understanding natural-language questions and ambiguity |
| Case 2 | Conversational context and dialogue state |
| Case 3 | Prompting strategies and chart generation |
| Case 4 | Chart specification validation and evaluation |
| Case 5 | Conversational chart editing and annotations |
| Case 6 | Failure analysis, Munzner's Nested Model and safeguards |
